# 수업판서 (ClassBoard)

안드로이드 전자칠판(Android 8.0 이상)용 **PDF 판서 앱**입니다.
수업 자료 PDF 위에 바로 필기하고, 필기는 자동으로 저장됩니다.

## 주요 기능

| 구분 | 기능 |
|---|---|
| PDF | USB · 구글 드라이브 · 내장 메모리에서 열기, 쪽 넘기기, 페이지 목록(썸네일), 확대/축소/이동 |
| 필기 | 펜(색 · 굵기 · 점선), 형광펜, 부분 지우개, 실행 취소/다시 실행, 페이지 전체 지우기 |
| 전자칠판 특화 | **손바닥으로 지우기**(접촉 크기 판별), 펜 굵은 쪽 지우개(선택), 두 손가락 확대/이동, 하단 플로팅 툴바(왼쪽/가운데/오른쪽 이동), 터치 보정 화면 |
| 필기감 | 손떨림 보정(1€ 필터, 끔/약/강), 펜 끝 위치 예측, 그리는 획만 다시 그리는 2단 레이어, 펜을 뗄 때 비트맵 갱신을 미뤄 끊김 방지 |
| 색 · 지우기 편의 | 펜을 대고 **길게 누르면 그 자리에 색·도구 메뉴**, 펜 굵은 쪽 = 지우개/두 번째 색/형광펜, **두 손가락 톡 = 실행 취소**, 부분/획 통째 지우개 |
| 도형 보정 | 그리고 **잠시 멈추면** 직선·꺾은선·삼각형·사각형·원/타원으로 자동 보정 (모든 획 자동 보정 옵션) |
| 도형 도구 | 직선, 화살표, 점선, 사각형, 원·타원, 삼각형, 직각삼각형, 좌표축, 수직선 |
| 수학 도구 | **자**(눈금, 회전, 변 따라 긋기), **각도기**(1° 단위 눈금, 중심에서 각도 긋기), **컴퍼스**(반지름 조절, 호/원 그리기) |
| 빈 페이지 | 무지 · 모눈 · 좌표평면 · 줄노트 · 점 격자, 흰색/칠판색/검정 배경. PDF 중간에 끼워 넣기 가능 |
| 저장 | PDF 를 앱 내부로 복사하고 필기를 자동 저장 → USB 를 빼도 다음 수업에 이어서 사용 |

## 설치

1. GitHub 의 **Actions → Build APK** 에서 최신 실행의 `classboard-apk` 를 내려받습니다.
   (또는 직접 빌드: `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`)
2. APK 를 USB 에 복사해 전자칠판에 꽂고, 파일 관리자에서 실행해 설치합니다.
   (처음이면 "알 수 없는 출처 허용"이 필요할 수 있습니다)

## 처음 사용할 때 — 터치 보정

IR 전자칠판마다 펜/손바닥의 접촉 크기 값이 다릅니다.
**설정 → 터치 보정**에서 펜 끝 · (굵은 쪽) · 손바닥을 각각 측정한 뒤 **자동 설정**을 누르세요.

## 사용 팁

- 칠판 앞에서 툴바까지 갈 필요 없이, **펜을 대고 0.5초 누르면** 그 자리에 색 · 펜/형광펜/지우개 · 실행 취소 · 전체 지우기 메뉴가 뜹니다.
- 두 손가락으로 화면을 **톡** 치면 실행 취소, 대고 움직이면 확대/이동입니다.
- 같은 도구 버튼을 **한 번 더 누르면** 굵기 · 색 · 점선 등 세부 패널이 열립니다.
- 자: 몸통을 끌면 이동, ↻ 손잡이로 회전(15° 단위로 착 붙음), **변 근처에서 그으면** 직선이 됩니다. 형광펜 상태면 형광펜 밑줄.
- 각도기: 중심점에서 시작해 그으면 1° 단위 반직선이 그어지고 각도가 표시됩니다.
- 컴퍼스: 회색 바늘 = 이동, 흰 손잡이 = 반지름 조절, 파란 연필 = 돌려서 호 그리기.

## 구조

```
app/src/main/java/com/classboard/app/
  model/Model.kt            페이지 · 획 데이터, JSON 저장 형식
  storage/DocumentStore.kt  PDF 가져오기, 저장/불러오기, PdfRenderer 래퍼
  ink/Geometry.kt           경로, 지우개 분할, 도형 생성
  ink/ShapeRecognizer.kt    손그림 → 도형 보정
  tools/MathTools.kt        자, 각도기, 컴퍼스
  ui/BoardView.kt           판서 화면 (렌더링 + 터치 처리)
  ui/BoardActivity.kt       툴바, 페이지 목록, 자동 저장
  ui/MainActivity.kt        첫 화면, 파일 열기
  ui/SettingsActivity.kt    설정, 터치 보정
```

외부 라이브러리 없이 안드로이드 기본 API(`PdfRenderer`, `Canvas`)만 사용합니다.
